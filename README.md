# Austin's Fantasy DD's

A table game for 2–4 players (or you vs. the CPU) on one phone or tablet. Each player has a wing-nut launcher that fires harpoon arrows at fluttering DD's. Lead your shots, reel in DD's worth 1, 2, 3 or 5 points, and grab power-ups for triple shot or no reload.

The whole game is one static page in `public/index.html`. It's deployed on Render as a static site with `public` as the publish directory.

Controls: tap your side of the screen to fire. On a keyboard, Z (bottom), Q (top), A (left), P (right).
